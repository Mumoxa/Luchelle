# My South African Hero — Natalie du Toit

An interactive Grade 3 oral presentation website.

- **Learner:** Luchelle Crafford
- **Class:** Grade 3A1
- **School:** Panorama Primary School, Cape Town
- **Hero:** Natalie du Toit, South African swimming champion

The matching editable PowerPoint (`Luchelle_Crafford_My_South_African_Hero.pptx`)
lives in the `downloads/` folder so it can be downloaded from the published site.

## What is inside

| File | Purpose |
| --- | --- |
| `index.html` | The six-slide presentation |
| `styles.css` | Springbok green-and-gold design, responsive layouts |
| `script.js` | Navigation: buttons, keyboard, swipe, dots, speaking words, sources |
| `assets/` | All photographs and the official Panorama Primary School crest (stored locally — nothing is hotlinked) |
| `downloads/` | The editable PowerPoint version of the same presentation |

## How to publish on GitHub Pages

1. Upload **all** the files in this folder (keeping the folder structure) to a
   GitHub repository — for example `my-south-african-hero`.
2. Open the repository's **Settings**.
3. In the left menu, select **Pages**.
4. Under *Build and deployment*, choose **Deploy from a branch**.
5. Select the **main** branch and the **/ (root)** folder, then click **Save**.
6. Wait a minute, then open the published URL that GitHub shows you
   (it looks like `https://<username>.github.io/<repository>/`).

## Using the presentation

- **Next / previous:** on-screen arrow buttons, the ← → arrow keys, the
  spacebar, or swiping left and right on a phone or tablet.
- **Speaking words:** the "Speaking words" button shows Luchelle's oral for
  the slide on screen.
- **Sources:** the "Sources" button opens the full fact and image credit list.
